GET STARTED

从选择项目，到拿到 APK

  1. 添加项目

    导入现有 Android 工程，或选择 UniApp 源码和匹配的 DCloud Android 模板。模板提供原生模块、图标和网络配置。

  2. 配置本机环境

    自动检测 HBuilderX、JDK、Android SDK。缺少 Java/Android 组件可在同意 SDK 许可后安装；HBuilderX 从官方安装并登录。

  3. 填写应用身份

    保存 AppID、包名、对应 AppKey 和证书。已有应用升级继续使用原证书；新应用可创建专用证书后登记到 DCloud。

  4. 一键构建

    启动 HBuilderX，保存配置，点击构建。工具创建独立副本、导出资源、编译签名并校验 APK，再安装到手机测试。

当前构建预设：UniApp / Vue3 + DCloud 5.34，AGP 8.12、Gradle 8.14.3。Mac、Windows、Linux 分别选择本机工具路径；跨平台分支中尚未在目标系统验证的部分，需完成一次出包验收。
